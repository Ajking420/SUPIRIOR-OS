# Office and accounting applications

## LibreOffice
LibreOffice Writer, Calc and Impress are included in the Core package selection.
They are native Linux applications and do not require a Microsoft or Tally licence.

## Microsoft 365
SUPERIOR OS provides a Microsoft 365 (Web) launcher that opens Microsoft's
online apps in Firefox. A Microsoft account and any required Microsoft 365
subscription are the user's responsibility.

The Windows desktop editions of Microsoft 365 are not bundled. They are
proprietary, licensed applications and are not guaranteed to run under Wine.
Users needing the full Windows desktop suite can use a properly licensed
Windows virtual machine on supported hardware.

## TallyPrime
SUPERIOR OS provides a launcher to the official TallyPrime download page.
The installer is proprietary and is not redistributed in this OS image.
Tally's published desktop requirements specify 64-bit Windows. Wine execution
on a user's own desktop is experimental and must be validated with the exact
TallyPrime release, licence activation, printing, Excel integration and company
data before production use. Do not use it with the only copy of accounting data.

For reliable use, use a properly licensed Windows installation/VM, or an
official Tally service that supports the user's Linux access scenario.
